# FNP-QNN WebMCP source contract

The dashboard discovers exactly twelve descriptors at `GET /webmcp/manifest`:
ten product tools backed by existing API handlers plus the two shared companion
tools. Invocation is denied until the host installs a trusted Gateway
`securedme.education.session.v2` resolver. The surface exposes no shell,
provisioning, E2B, browser automation, `.env`, private CeLeBrUm corpus, clinical
inference, or unsupported backend. Unavailable candidates remain unavailable.

Theme provenance is the product-specific Stitch handoff
`securedme-site/assets/landing/secureme.ca-product/education/FNP-QNN-MVP/desing/stitch_fnp_qnn_research_simulator_design_system/stitch_fnp_qnn_research_simulator_design_system/desing.md`
with `sourceStatus: verified-product-stitch`.
Its navy/gold/cyan tokens are consumed as CSS custom properties; high-contrast
system fonts, visible focus, and text-first status labels are the fallback.
