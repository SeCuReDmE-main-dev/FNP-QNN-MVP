# Institutional Demo Script

Date: `2026-06-17`

## Positioning

FNP-QNN is an alpha-local, non-clinical educational research simulator. It demonstrates a reproducible local evidence workflow, a deterministic fallback runtime, and a visual Network Designer path for neural, QNN, spiderweb, memory graph, crossmodal, logic, and custom network experiments.

## Three-minute flow

1. Open with the boundary.
   - This is not clinical, diagnostic, therapeutic, emergency, safety-critical, or production-public software.
   - Results are local simulation evidence only.

2. Show the local operator dashboard.
   - Use `docs/outreach/screenshots/panel-app-overview.png`.
   - Point to the Panel dashboard as the local control-room surface.

3. Show the Network Designer path.
   - Use `docs/outreach/screenshots/network-designer-view.png`.
   - Explain that the backend contract is implemented and tested, with Qiskit lanes visible but optional/gated.

4. Show evidence and validation.
   - Use `docs/outreach/screenshots/evidence-status-view.png`.
   - Cite the validation commands in `reports/mission_smoke_2026-06-17.md`.

5. Explain optional operations.
   - Datadog and E2B are used as optional audit/observability workflows for sandbox evidence.
   - They are not claimed as production security, clinical validation, or public deployment proof.

## Closing ask

The project is ready for a first supervised institutional review focused on reproducibility, safe local hosting, educational value, and next-step research governance.
