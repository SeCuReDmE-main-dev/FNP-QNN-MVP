# Roadmap

This roadmap is public-safe and non-clinical. It tracks MVP hardening, not a
medical or production deployment plan.

## Current Foundation

- FastAPI local research API.
- HoloViz Panel local operator dashboard.
- Cerebrum-shaped runtime fixtures.
- Deterministic Torch surrogate fallback.
- NeuroBit gate profile, gate trace, tunnel-noise demo, and tests.
- Alpha-readiness validation script.

## Near-Term Milestones

### M1 - Public OSS Readiness

- Add license, education, roadmap, and code of conduct files.
- Keep README language bounded and maintainer-guided.
- Document contribution and validation commands.

### M2 - FNP-QNN Primitive Transfer

- Keep NeuroBit gates dependency-light and public-safe.
- Add deterministic experiment seed manager.
- Add amplitude/phase feature transforms.
- Add CLI demos and tests for transferred primitives.

### M3 - Panel Repair

- Apply `DESIGN.md` hierarchy.
- Move brand/product imagery below runtime evidence.
- Prefer panel-ready generated assets.
- Add screenshot QA after major UI changes.

### M4 - Network Designer Backend

- Add graph model, registry, presets, validator, serialization, and executor.
- Do not start with drag-and-drop JavaScript before the graph contract exists.
- Keep Qiskit lanes visible but gated by availability.

### M5 - Institutional Package

- Maintain `FNP_QNN_INSTITUTIONAL_BRIEF.md`.
- Maintain `SECURITY_MODEL.md`.
- Prepare public-safe screenshots and demo script.

## Explicit Non-Goals

- Clinical claims.
- Security/encryption claims from NeuroBit tunnel metadata.
- Wholesale import of full private FNP-QNN modules.
- Heavy UI or runtime dependency creep.
- Public exposure of private CeLeBrUm material.
