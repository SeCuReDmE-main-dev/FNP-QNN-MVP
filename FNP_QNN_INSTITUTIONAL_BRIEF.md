# FNP-QNN Institutional Brief

## One-Sentence Summary

FNP-QNN is a local educational research control room for building, testing, and
visualizing experimental memory-to-network simulation pipelines.

French:

FNP-QNN est un cockpit local de recherche pour construire, tester et visualiser
des pipelines experimentaux memoire -> encodage -> reseau -> evidence.

## What Exists Now

- FastAPI local research API.
- HoloViz Panel local dashboard.
- Deterministic Torch fallback lane.
- NeuroBit gate profile and trace demo.
- Fixture-backed Cerebrum-style runtime examples.
- Unit tests and alpha-readiness validation.

## What Is Intentionally Not Claimed

- No clinical or diagnostic use.
- No treatment recommendation.
- No medical-grade validation.
- No production security guarantee.
- No claim that NeuroBit tunnel metadata is encryption.
- No claim of real quantum execution unless the optional backend reports it.

## Why It Is Institutionally Useful

The project can support supervised learning or research software engineering
work around reproducible local simulation, feature encoding, QNN candidate
boundaries, visual network workflow design, and evidence-based reporting.

## Near-Term Support Needs

- Panel cleanup following `DESIGN.md`.
- Public-safe asset preparation.
- Network Designer backend contract.
- Additional deterministic FNP-QNN primitives.
- Reproducible demos and screenshots.
- Supervised compute or lab-hosted sandbox evaluation.

## Private Boundary

CeLeBrUm is a private local evidence/memory server and is not the public demo
layer. Private corpus text, secrets, unpublished research, and local tokens
must not be exposed in public FNP-QNN materials.
